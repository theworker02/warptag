# warptag

Warp structured JSON tag payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/warptag/

## Install / run

```bash
git clone https://github.com/theworker02/warptag.git
cd warptag
node src/cli.js
node --test
```
